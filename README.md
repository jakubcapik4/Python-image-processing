# Python Image Processing

A Python desktop application developed as a student project for searching, browsing, and editing images.

## Features

- Search for image files by extension in a selected directory and its subdirectories.
- Browse images using a graphical interface.
- Apply image-processing filters, including bilateral filtering and histogram equalization.
- Add text watermarks to images.
- Resize images using OpenCV.
- Display image previews in a gallery.

## Technologies

- Python
- Tkinter
- OpenCV
- Pillow
- NumPy

## Project Structure

- `image_processing.py` — main Python script.
- `images/` — sample images used by the application.
- `image_processing_dokumentácia.docx` — project documentation.

## Getting Started

1. Install Python 3.
2. Install the required libraries:

   ```
   pip install opencv-python pillow numpy
   ```

3. Run the application:

   ```
   python image_processing.py
   ```
